Aviator is an LLM routing library that automatically selects the right model
for each query — so you stop paying frontier prices for simple tasks.

Drop it into your existing agent setup with one command. Aviator scores every
query against a heuristic engine, picks the most cost-effective model that can
handle it, and shows you exactly what you saved.

> ⚠️ This project is under active development and not yet ready for use.
